# ANEMOS - Luxury Hotel Digital Concierge & QR Menu System

A modern, responsive, and completely free web-based Digital Concierge and QR Menu application designed for luxury hotels and resorts. Inspired by premier hospitality guest experience platforms.

## ✨ Features

### 📱 1. Guest Experience Portal (`index.html`)
- **Splash Screen:** Elegant luxury branding animation.
- **Room Selector:** Easy room check-in selection modal (Room 101–999).
- **Time-Based Dynamic Greeting:** Updates automatically (Good Morning, Afternoon, Evening, Night).
- **24/7 Smart Concierge Chat:** Interactive real-time chat with automated helpful responses for food, spa, laundry, and cleaning requests.
- **Hotel Services & Menus:**
  - 🥐 **Breakfast Menu:** Full digital menu with dietary tags (Veg, Vegan, Chef Special) and prep times.
  - 📶 **House & Wi-Fi:** One-click Wi-Fi details, password display, and property operating hours.
  - 🛎️ **Guest Services:** Instant one-tap requests (Extra Pillows, Towels, Room Cleaning, DND, Wake-up call).
  - 🧭 **Local Attractions Guide:** Curated local recommendations, beaches, distances, and drive times.
  - 📞 **Hotel Directory:** Reception, Housekeeping, Restaurant, Spa, and Valet extensions with call triggers.
  - 🍷 **Mini Bar Service:** In-room minibar items with direct add-to-room-bill functionality.
  - 💆 **Spa & Wellness:** Treatments booking with instant confirmation toast.
  - 🗺️ **Property Map & Policies:** Property layout and guest guidelines.

### 🖥️ 2. Staff / Admin Dashboard (`staff.html`)
- **Live Guest Requests:** Real-time sync of all guest requests and orders.
- **Status Management:** Mark requests as *Pending*, *In Progress*, or *Completed*.
- **QR Code Generator:** Built-in QR code generator for each room number, ready to print for guest rooms.

## 🚀 Getting Started

No dependencies or build steps required. Simply open `index.html` in any web browser or host on GitHub Pages:

```bash
# Clone the repository
git clone https://github.com/vaibhavsarnobat1-bit/anemos-hotel-concierge.git

# Open the project folder
cd anemos-hotel-concierge
```

---

## 🌐 Free Hosting via GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and `/root`.
4. Click **Save**. Your site will be live on `https://vaibhavsarnobat1-bit.github.io/anemos-hotel-concierge/`!
